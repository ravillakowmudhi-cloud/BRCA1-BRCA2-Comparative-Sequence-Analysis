# Comparative Sequence Analysis of BRCA1 and BRCA2

Comparative sequence analysis of human BRCA1 and BRCA2 using GC content, GC/AT skew, ORF detection, SNP mutation simulation, and statistical testing.

## Overview

This project computationally compares the human BRCA1 (NCBI RefSeq NM_007294.4) and BRCA2 (NM_000059.4) reference gene sequences using nucleotide composition analysis, sliding-window GC/AT skew, open reading frame (ORF) detection, simulated SNP mutation analysis, and statistical hypothesis testing (Welch two-sample t-test). The pipeline combines Linux (data retrieval), Python with Biopython (sequence analysis), and R (statistical testing and visualization).

## Key Finding

BRCA1 shows a significantly higher GC content than BRCA2 (41.77% vs. 36.18%; Welch two-sample t-test, p = 2.11 × 10⁻¹⁴).
